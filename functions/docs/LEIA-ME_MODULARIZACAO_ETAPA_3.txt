ARIANA MÓVEIS - MODULARIZAÇÃO ETAPA 3

Módulo Enterprise: Pedidos, Status, Tracking, NF-e e Logs.

O que foi adicionado:

1) GET /api/enterprise/orders
   Lista pedidos recebidos pela camada enterprise. Uso interno/admin.

2) POST /api/enterprise/orders
   Recebe ou atualiza um pedido vindo de fabricante/ERP.
   Requer header:
   x-ariana-key: ENTERPRISE_WEBHOOK_SECRET

3) POST /api/enterprise/orders/:orderId/status
   Atualiza status do pedido por ID interno ou externalOrderId.

4) POST /api/enterprise/orders/:orderId/tracking
   Recebe rastreio e transportadora do fabricante/seller/ERP.

5) POST /api/enterprise/orders/:orderId/invoice
   Recebe dados de NF-e/DANFE/XML do fabricante.

6) GET /api/enterprise/logs
   Lista logs das integrações.

7) GET /api/enterprise/queue
   Lista fila de envio para fabricantes.

IMPORTANTE:
Esta etapa não altera checkout, pagamentos, seller, Correios ou carrinho.
Ela apenas adiciona uma camada nova para integração empresarial.
