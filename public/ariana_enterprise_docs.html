A integração pode ser feita por API Key, OAuth 2.0 Client Credentials, SDK oficial ou chamadas HTTP diretas. Para produção, o fabricante precisa concluir a homologação automática e receber a liberação no Admin Enterprise.

SDK

Bibliotecas JavaScript, Node.js, PHP, Python e Java prontas para ERP.

Autenticação

Use x-ariana-key ou Authorization: Bearer.

curl -H "x-ariana-key: ari_live_xxxxx" \ https://ariana-backend.onrender.com/api/v1/enterprise/health

OAuth 2.0

POST /api/enterprise/oauth/token { "grant_type":"client_credentials", "client_id":"ari_client_xxxxx", "client_secret":"ari_secret_xxxxx" }

Ambientes e versionamento

Base estável: /api/v1/enterprise

Próxima versão: /api/v2/enterprise

Use v1 em produção. Use v2 apenas para testes e recursos futuros.

Fluxo recomendado

  1. Solicitar homologação.
  2. Receber API Key Sandbox.
  3. Testar catálogo, estoque, preço, pedido, NF-e e rastreio.
  4. Executar homologação automática.
  5. Receber liberação de produção.
  6. Ativar webhooks e monitorar consumo.

Payloads essenciais

Pedido

{ "manufacturer":"ariana_moveis", "externalOrderId":"PED-0001", "customerName":"Cliente Teste", "items":[{"sku":"ARI-0001","qty":1,"unitPrice":2299}] }

Webhooks

Eventos enviados ao ERP do fabricante com assinatura HMAC quando configurado.

Eventos: order_created, payment_approved, invoice_received, tracking_updated, order_cancelled

SDK PHP

Instale o pacote PHP/Composer para integrar ERPs brasileiros sem montar HTTP manualmente.

composer require ariana/enterprise-sdk
use ArianaEnterprise\\Client;
$api = new Client(['apiKey' => 'ari_live_xxxxx', 'environment' => 'production']);
$api->catalog()->push([['sku'=>'ARI-0001','name'=>'Produto Teste','price'=>2299,'stock'=>10]]);

Baixar SDK PHP Manifest PHP

SDK Python

Instale o pacote Python/Pip para integrar ERPs, automações e pipelines de dados sem montar HTTP manualmente.

pip install ariana-enterprise
from ariana_enterprise import ArianaEnterpriseClient

api = ArianaEnterpriseClient(api_key='ari_live_xxxxx', environment='production')
api.catalog.push([{'sku':'ARI-0001','name':'Produto Teste','price':2299,'stock':10}])

Baixar SDK Python Manifest Python

SDK Java

Indicado para ERPs corporativos, Spring Boot, Jakarta EE e integrações JVM.

<dependency> <groupId>br.com.arianamoveis</groupId> <artifactId>ariana-enterprise-java</artifactId> <version>1.0.0</version> </dependency>
ArianaEnterpriseClient ariana = ArianaEnterpriseClient.builder() .apiKey("ari_live_xxxxx") .environment("production") .build(); ariana.catalog().push(List.of( Map.of("sku", "ARI-0001", "name", "Produto Teste", "price", 2299, "stock", 10) ));

Baixar SDK Java Manifest Java
