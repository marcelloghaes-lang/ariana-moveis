Comece por aqui

A integração pode ser feita por API Key, OAuth 2.0 Client Credentials, SDK oficial ou chamadas HTTP diretas. Para produção, o fabricante precisa concluir a homologação real no Sandbox: o Ariana Enterprise valida evidências das chamadas executadas de verdade antes de permitir a liberação no Admin Enterprise.

Sandbox

Testes e homologação sem impacto real.

Produção

Operação real após aprovação.

SDK

Bibliotecas JavaScript, Node.js, PHP, Python e Java prontas para ERP.

Autenticação

Use x-ariana-key ou Authorization: Bearer.

curl -H "x-ariana-key: ari_live_xxxxx" \ https://ariana-backend.onrender.com/api/v1/enterprise/health

OAuth 2.0

POST /api/v1/enterprise/oauth/token { "grant_type":"client_credentials", "client_id":"ari_client_xxxxx", "client_secret":"ari_secret_xxxxx" }

Ambientes e versionamento

Base estável: /api/v1/enterprise

Próxima versão: /api/v2/enterprise

Use v1 em produção. Use v2 apenas para testes e recursos futuros.

Fluxo recomendado

  1. Solicitar homologação.
  2. Receber API Key Sandbox.
  3. Testar catálogo, estoque, preço, pedido, NF-e e rastreio.
  4. Solicitar a verificação da homologação real; o sistema calcula o score pelas evidências registradas no Sandbox.
  5. Receber liberação de produção.
  6. Ativar webhooks e monitorar consumo.

Webhooks

Eventos enviados ao ERP do fabricante com assinatura HMAC quando configurado.

Eventos: order_created, payment_approved, invoice_received, tracking_updated, order_cancelled

SDK PHP

Baixe o pacote ZIP oficial e adicione o SDK ao seu projeto. A publicação em registry público deve ser considerada disponível somente quando indicada oficialmente pela Ariana Enterprise.

use ArianaEnterprise\\Client;
$api = new Client(['apiKey' => 'ari_live_xxxxx', 'environment' => 'production']);
$api->catalog()->push([['sku'=>'ARI-0001','name'=>'Produto Teste','price'=>2299,'stock'=>10]]);

SDK Python

Baixe o pacote ZIP oficial e adicione o SDK ao seu projeto Python. A publicação em PyPI será informada oficialmente quando estiver disponível.

from ariana_enterprise import ArianaEnterpriseClient

api = ArianaEnterpriseClient(api_key='ari_live_xxxxx', environment='production')
api.catalog.push([{'sku':'ARI-0001','name':'Produto Teste','price':2299,'stock':10}])

SDK Java

Baixe o ZIP oficial para integrar ERPs corporativos, Spring Boot, Jakarta EE e aplicações JVM. A publicação em Maven Central será informada oficialmente quando estiver disponível.

ArianaEnterpriseClient ariana = ArianaEnterpriseClient.builder() .apiKey("ari_live_xxxxx") .environment("production") .build(); ariana.catalog().push(List.of( Map.of("sku", "ARI-0001", "name", "Produto Teste", "price", 2299, "stock", 10) ));
