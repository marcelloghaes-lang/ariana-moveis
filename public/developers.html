Visão geral

A API Ariana Enterprise permite que parceiros enviem produtos, atualizem preço e estoque, recebam pedidos e devolvam informações operacionais como NF-e e rastreio.

Base de produção: https://ariana-backend.onrender.com/api

Formato

Todas as requisições usam JSON e HTTPS.

Os dados exibidos nesta documentação são exemplos demonstrativos da Ariana Móveis. Não representam parceria oficial com marcas ou fabricantes terceiros.
Content-Type: application/json

Autenticação

As APIs externas de fabricantes usam a chave configurada pela Ariana Móveis. Essa chave deve ser enviada no header x-ariana-key.

x-ariana-key: SUA_CHAVE_DE_INTEGRACAO
Content-Type: application/json
A chave real não deve ser compartilhada publicamente. Ela será fornecida durante a homologação técnica.

Catálogo de produtos

POST/enterprise/catalog/push

Envia um ou mais produtos do fabricante para cadastro ou atualização no marketplace.

{
  "manufacturer": "ariana_moveis_demo",
  "sellerId": "ariana_moveis_demo",
  "sellerName": "Ariana Móveis Demo",
  "items": [
    {
      "sku": "ARIANA-DEMO-001",
      "name": "Produto Teste Ariana Enterprise",
      "description": "Produto recebido via catálogo Enterprise.",
      "category": "Geladeiras & Refrigeradores",
      "brand": "Ariana Móveis Demo",
      "price": 2500,
      "stock": 12,
      "weight": 60,
      "height": 175,
      "width": 70,
      "length": 70,
      "imageUrl": "https://exemplo.com/produto.jpg"
    }
  ]
}

Resposta esperada

{
  "ok": true,
  "manufacturer": "ariana_moveis_demo",
  "total": 1,
  "success": 1,
  "errors": 0
}

Sincronização de estoque, preço e status

POST/enterprise/products/{sku}/sync

Atualiza preço, estoque, disponibilidade e status de um produto já cadastrado.

{
  "manufacturer": "ariana_moveis_demo",
  "price": 2299,
  "stock": 3,
  "active": true,
  "availability": "available",
  "status": "updated_by_erp"
}

Também disponíveis

PUT/enterprise/products/{sku}/stock
PUT/enterprise/products/{sku}/price

Recebimento de pedidos

POST/enterprise/orders

Recebe ou atualiza pedido vindo de fabricante, distribuidor ou ERP.

{
  "manufacturer": "ariana_moveis_demo",
  "externalOrderId": "ARIANA-DEMO-001",
  "customerName": "Cliente Teste",
  "customerEmail": "cliente@teste.com",
  "customerPhone": "31999999999",
  "items": [
    {
      "sku": "ARIANA-DEMO-001",
      "name": "Produto Teste Ariana Enterprise",
      "qty": 1,
      "unitPrice": 2500,
      "sellerId": "ariana_moveis_demo"
    }
  ]
}

Rastreamento

POST/enterprise/orders/{orderId}/tracking

Atualiza transportadora, código e URL de rastreamento.

{
  "manufacturer": "ariana_moveis_demo",
  "trackingCode": "TESTE123456789BR",
  "carrier": "Transportadora Ariana",
  "trackingUrl": "https://rastreamento.teste.com/TESTE123456789BR"
}

NF-e, DANFE e XML

POST/enterprise/orders/{orderId}/invoice

Envia dados fiscais do pedido.

{
  "manufacturer": "ariana_moveis_demo",
  "invoice": {
    "number": "12345",
    "series": "1",
    "accessKey": "31260600000000000000550010000123451000012345",
    "danfeUrl": "https://teste.com/danfe-12345.pdf",
    "xmlUrl": "https://teste.com/nfe-12345.xml",
    "total": 2500
  }
}

Webhooks

POST/enterprise/webhooks/{manufacturer}

Endpoint para eventos gerais do fabricante, como confirmação de recebimento, separação, faturamento ou expedição.

{
  "event": "order_ack",
  "externalOrderId": "ARIANA-DEMO-001",
  "status": "received",
  "message": "Pedido recebido pelo ERP de demonstração"
}

Códigos de erro

200 / 201
Operação concluída com sucesso.
400
Payload inválido ou campo obrigatório ausente.
401
Chave de integração inválida ou ausente.
403
API externa não liberada ou segredo não configurado.
404
Pedido ou produto não encontrado.
500
Erro interno de processamento.

Processo de homologação

  1. Cadastro comercial do fabricante.
  2. Liberação de chave de teste.
  3. Envio de catálogo piloto.
  4. Teste de estoque, preço e disponibilidade.
  5. Teste de pedido, NF-e e rastreio.
  6. Aprovação para produção.
